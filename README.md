# DFM Realtime Studio

Chrome extension for the Dragonfruit team: realtime views, trends, A/B tests and title/thumbnail changes for our client channels, plus the packaging card inside YouTube Studio.

- **Teammates → [Install & setup](https://dragonfruit-media-co.github.io/studio-realtime-updates/)** (2 minutes, with screenshots)
- **Workspace admin → [Managed install](https://dragonfruit-media-co.github.io/studio-realtime-updates/admin.html)** (one policy, 5 minutes)

This repository only hosts the release files (`update.xml`, the signed `.crx`, the `.zip`) and the two pages above. The source is private.
