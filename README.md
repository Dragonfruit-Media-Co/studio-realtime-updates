# DFM Realtime Studio — update feed

Hosted on GitHub Pages: https://dragonfruit-media-co.github.io/studio-realtime-updates/

- `update.xml` — Omaha update manifest for the managed (force-installed) Chrome extension
- `dfm-realtime-studio.crx` — the signed package Chrome downloads from it
- `dfm-realtime-studio.zip` — the same files for a manual "Load unpacked" install
- `index.html` — install page for teammates

Written by `scripts/release.mjs` in the private source repository `Dragonfruit-Media-Co/studio-realtime`.
No source code lives here.
