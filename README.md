# DFM Realtime Studio

Chrome extension for the Dragonfruit team: realtime views, trends, A/B tests and title/thumbnail changes for our client channels, plus the packaging card inside YouTube Studio.

- **Teammates → [Install & setup](https://dragonfruit-media-co.github.io/studio-realtime-updates/)** (2 minutes, with screenshots). Tokens: [ClickUp API](https://app.clickup.com/24512108/settings/team/24512108/clickup-api) · [Notion tokens](https://app.notion.com/developers/tokens?spaceId=7d4d8320-1d73-4f53-b244-c99554ac51f8)
- **Workspace admin → [Managed install](https://dragonfruit-media-co.github.io/studio-realtime-updates/admin.html)** (one policy, 5 minutes)

This repository only hosts the release files (`update.xml`, the signed `.crx`, `dfm-realtime-studio-<version>.zip` plus a stable `dfm-realtime-studio.zip` alias) and the two pages above. The source is private.
