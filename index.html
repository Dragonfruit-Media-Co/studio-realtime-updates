DFM Realtime Studio v0.6.0

Chrome extension for the Dragonfruit team: realtime views, trends, A/B tests and title/thumbnail changes for client channels, plus the packaging card in YouTube Studio.

Managed install (preferred)

If your Chrome profile is signed in with your @dragonfruitmedia.co account and the admin has applied the policy, the extension installs and updates by itself. Nothing to do.

Manual install (until the policy is in place)

Download dfm-realtime-studio.zip

  1. Unzip it. Keep the folder somewhere permanent (not Downloads).
  2. Open chrome://extensions, switch on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped dfm-realtime-studio folder.
  4. Pin the icon, open it, paste your ClickUp API token and your Notion token, press Save.

Updates: download the zip again and unzip over the same folder, then press the reload arrow on chrome://extensions. The managed install does this automatically.
